FORMA — VERSION INSTALLABLE ET SYNCHRONISÉE
=====================================================

Cette version enregistre tes séances sur ton compte Google (Firebase, comme ta Matrice d'Eisenhower)
et récupère automatiquement tes activités Garmin via Strava.

1. FIREBASE (5 min)
   Le plus simple : ouvre le site, onglet Activités ou Réglages → « Configurer ».
   L'app affiche où trouver la configuration, une zone pour la coller, le domaine et la règle
   à copier. Elle l'enregistre sur l'appareil et fournit un lien pour configurer tes autres appareils.

   Sinon, à la main :
   a. Ouvre firebase-config.js et colle la configuration de ton projet Firebase existant
      (Console Firebase → ⚙ Paramètres du projet → Vos applications → Configuration du SDK).
   b. Authentication → Settings → Domaines autorisés → ajoute l'adresse de ton site Netlify
      (ex. gilded-cucurucho-1204fa.netlify.app).
   c. Firestore → Règles : ajoute ce bloc dans « match /databases/{database}/documents { ... } »
      puis Publier :

        match /users/{uid}/{document=**} {
          allow read, write: if request.auth != null && request.auth.uid == uid;
        }

2. STRAVA : RIEN À FAIRE ICI
   La configuration se fait dans l'app (onglet Activités) : elle ouvre la page Strava API,
   affiche les valeurs à copier et enregistre ton Client ID / Client Secret sur ton compte.
   Vérifie seulement que ta montre est reliée à Strava :
   Garmin Connect → Paramètres → Applications partenaires → Strava.

3. VARIABLES NETLIFY : FACULTATIVES
   Si tu préfères, tu peux mettre STRAVA_CLIENT_ID et STRAVA_CLIENT_SECRET dans
   Netlify → Site configuration → Environment variables. Elles remplacent alors la saisie dans l'app.

4. DÉPLOIEMENT
   Le glisser-déposer (Netlify Drop ou « Deploys » → déposer un dossier) ne publie pas la fonction
   Strava (dossier netlify/functions). Deux solutions :

   A) Avec GitHub, sans terminal :
      - crée un dépôt sur github.com (privé si tu veux) ;
      - « Add file » → « Upload files » → dépose tout le CONTENU de ce dossier, y compris le dossier
        netlify (depuis un ordinateur) → Commit ;
      - Netlify → ton site → Site configuration → Build & deploy → Link repository → choisis le dépôt.
        Laisse « Build command » vide et « Publish directory » à « . ».
      Chaque modification poussée sur GitHub redéploie le site.

   B) En ligne de commande, depuis ce dossier (Node.js installé) :
      npx netlify-cli login
      npx netlify-cli link        (choisis ton site existant)
      npx netlify-cli deploy --prod --dir .

5. SUR TON TÉLÉPHONE
   Ouvre le site dans Chrome → « Se connecter » (Google) → onglet Activités → « Connecter Strava ».
   Puis menu ⋮ → Installer l'application (ou le bouton « Installer l'app » en haut).
   Ensuite, chaque ouverture de l'app récupère tes nouvelles séances.

Les séances déjà présentes sur l'appareil sont envoyées sur ton compte à la première connexion.
Le coach IA reste disponible uniquement dans la version Claude ; les conseils automatiques fonctionnent partout.
